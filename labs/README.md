# Labs

การทดลองเดือนละครั้ง (สัปดาห์ 4, 8, 12) เพื่อดูของจริงที่ design doc เดาไว้

แต่ละการทดลองอยู่ในโฟลเดอร์ของตัวเอง:

```
labs/wNN-ชื่อการทดลอง/
├── compose.yaml
└── README.md
```

`README.md` ของแต่ละการทดลองมี 3 หัวข้อ:

1. **สมมติฐาน** — เขียนก่อนรัน: คิดว่าจะเกิดอะไร ตัวเลขเท่าไร
2. **วิธีทดลอง** — คำสั่งที่รัน และสิ่งที่ทำให้ระบบพัง (หยุด container, ตัด network, ยิงโหลด)
3. **ผล** — เกิดอะไรจริง ตรงหรือไม่ตรงกับสมมติฐานตรงไหน และเพราะอะไร

รัน: `docker compose -f labs/wNN-ชื่อการทดลอง/compose.yaml up`
